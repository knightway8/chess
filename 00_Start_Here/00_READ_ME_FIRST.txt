Chess Text Library
==================

This is a prose-only chess learning library. It contains no board diagrams and no move
sequences. The named-opening catalog covers 3,174 distinct labels from 3,810 source records
in a 141-file normalized family index.

START HERE

Read Foundations, then Decision Process, Loose Pieces, Pawn Chains, Endgame Thinking, and
What an Opening Should Accomplish. Use the other folders as a reference. Pair exact tactics
and endings with a legal board, because prose cannot define an exact position.

WHAT “SECRETS” MEANS HERE

There are no magic moves. The durable secrets are habits: notice what changed, check forcing
replies, improve the least useful piece, prepare pawn breaks, respect the opponent’s best
resource, and judge the position after an exchange.

ACCURACY BOUNDARIES

Opening labels are a broad public reference snapshot, not a claim that every historical
nickname in every language is known. Strategic examples are relational thought experiments,
not forced lines. Competition rules can change; consult the current organizer or federation.

ENCODING

All files are UTF-8 plain text with line feeds. The library can be searched, edited,
printed, or published as static text.
