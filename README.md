# Chess — Text Learning Library

Text files for chess: **173 plain-text files** covering chess understanding, openings, calculation, practical play, training, and reference, plus a downloadable ZIP of the library.

## Start reading

1. Open [Read Me First](00_Start_Here/00_READ_ME_FIRST.txt).
2. Use the [complete file index](00_Start_Here/01_COMPLETE_FILE_INDEX.txt) to find a subject.
3. Browse the numbered folders, or download [Chess_Text_Library.zip](Chess_Text_Library.zip) and extract it for offline reading.

You can also select **Code → Download ZIP** to save the whole repository. Text lessons open in a normal text editor on a computer or phone.

## Subjects

- **01–09:** foundations, thinking and calculation, tactics, positional play, pawns, pieces, attack, defense, and exchanges.
- **10–18:** endgames, opening understanding, open games, the Sicilian, other king-pawn defenses, queen-pawn openings, Indian defenses, flank systems, and unusual openings.
- **19–24:** chess mathematics, training methods, competition and psychology, thought experiments, glossary and reference, and opening names.
- **25:** [sources and reuse guidance](25_Sources_And_Reuse).

## Changes and protection

The default branch is protected against force pushes and branch deletion. Changes go through a pull request, with no user or app bypass exemptions. Independent review approval is not required, so the owner can maintain the library without another collaborator.

Files can still be edited or deleted through a merged pull request. The owner can change the protection rules or delete the entire repository. Keep a local copy of material you want to retain.

## Use and corrections

Follow the licenses, credits and reuse instructions included with each collection. If you find an error, identify the course, file, page or section, and the move or explanation that needs correction.
